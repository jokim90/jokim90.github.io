# jokim90.github.io

Jungrun Kim — career portfolio (single-page, WebGL globe).

- `index.html` — the site. Edit this file and push to `main`; GitHub Actions deploys it.
- Language: the page is written in English; Korean strings live in the `KO` dictionary in the script at the end of `index.html` and are swapped in by the EN / KO toggle (elements carry `data-i18n` keys). When you edit copy, update both.
- `images/work/korean-doctors/` — screenshots for Case 02 (Korean Doctors).
- `resume/` — downloadable resume PDF linked from the hero button.
- `docs/`, `images/` — assets kept from the previous site so existing links keep working.
- The previous Next.js site is preserved on the `nextjs-legacy` branch.
- Source of this page is also mirrored at `jokim90/portfolio-3d`.
